# Desktop (Windows / Linux / macOS)

Готовые сборки — на странице **Releases** (`PixelPisun-windows-x86_64.zip`, `PixelPisun-linux-x86_64.tar.gz`).

Запуск из исходников (нужен Python 3.9+):

- Windows: двойной клик по `desktop/run.bat`
- Linux/macOS: `./desktop/run.sh`
- Вручную: `pip install pygame` → `python main.py` (`--fullscreen` — сразу на весь экран)

## Управление
← → / A D — ход · Пробел / Z / K — прыжок (в воздухе двойной) · Shift — бег · ↑ W / ↓ S — лестница (режим «Генерация») ·
G / F / X — граната · E / Enter — «ПОСТРОИТЬ» и реплики · Esc / P — пауза · F11 — полный экран. Мышь работает в меню.

## Кооп с телефонами
Одна сеть Wi-Fi; КО-ОП → «Создать игру» или выбери сервер в списке. Windows при первом запуске спросит про брандмауэр —
разреши доступ в частных сетях. Если список пуст (изоляция клиентов, гостевая сеть) — кнопка «ПО IP» и адрес хоста из лобби.
Порты: UDP 47310, TCP 47311–47322.

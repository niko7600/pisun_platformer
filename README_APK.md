# Сборка APK в облаке (GitHub Actions)

Termux для этого не годится: buildozer / python-for-android скачивают Android SDK/NDK
для x86-Linux, на телефоне они не запустятся. Поэтому собираем на серверах GitHub (бесплатно).

1. Зарегистрируйся на github.com (если нет аккаунта) и создай новый репозиторий (можно приватный).
2. Залей в него всё содержимое этой папки: main.py, levelgen.py, citydraw.py, battlemap.py, battle.py, buildozer.spec и папку .github
   (в веб-интерфейсе: Add file -> Upload files; папку .github надо загружать вместе с вложенной
   workflows/build-apk.yml, поэтому проще через git или GitHub Desktop).
3. Открой вкладку Actions -> «Build APK» -> Run workflow. Первая сборка идёт 20-40 минут
   (качает SDK/NDK и собирает pygame), следующие быстрее за счёт кэша.
4. Когда сборка зелёная, открой её и внизу, в разделе Artifacts, скачай pisun-apk.
   Распакуй zip, внутри .apk. Скопируй на телефон, разреши установку из неизвестных
   источников и установи.

Если сборка упала — открой лог шага «Сборка debug APK», скопируй последние ~50 строк
и пришли мне, поправлю buildozer.spec.

Заметки:
- main.py — это копия pisun_mobile.py (сама игра). Рядом должны лежать ещё четыре модуля, без них игра не запустится:
  levelgen.py и citydraw.py — генератор и рисование города (режим «Генерация»),
  battlemap.py — готовая карта режима «Битва за Писюн», battle.py — сюжет, строительство, босс и финал этого режима.
  При обновлении заливай все пять .py файлов (заменяя старые) и снова запускай Actions.
- Режим «Битва за Писюн» при первом входе несколько секунд готовит звуки и ночную графику (индикатор загрузки на экране) — это нормально. На слабых телефонах игра сама упрощает часть эффектов.
- Название на иконке: title в buildozer.spec (сейчас латиницей, чтобы не было проблем со сборкой).
- Версии инструментов закреплены (p4a v2023.09.16, NDK 25b, Python 3.10): не обновляй их, иначе pygame 2.1 перестанет собираться.
- Это debug-APK для установки вручную, для Google Play он не подходит.

Fonts: the game does not ship any font files. It uses a Cyrillic-capable font that is
already installed on the user's system (Arial, DejaVu Sans, Liberation Sans, Roboto, ...).
If none is found, pygame's built-in font is used (GNU FreeFont, GPL 2.0 with the font
exception, which allows embedding in programs without affecting their license).

Everything else (graphics, sounds, music) is drawn or synthesized by the game's
code at runtime; no external assets are included.
